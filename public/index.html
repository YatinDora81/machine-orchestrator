Your laptopOpens the onrender.com URL on port 443.
Render edgeForwards that traffic to the one port this page already bound.
Other processA dev server on 3000 or 5173 stays inside the container, or on Render’s private network.
Probe from inside the container, then open the public link from this browser.

On Render, the public link uses the hostname with that port number. The edge does not route it into the container, so the page should fail to load even when the inside probe says the port is open.

On your own laptop, while this app is running locally, extra ports really are reachable. A local success does not mean Render will publish them.

Create React App reads PORT from the environment. This service already uses that variable, so start the app with an override: PORT=3000 HOST=0.0.0.0 BROWSER=none npm start. Binding 0.0.0.0 still does not make Render publish that port.
